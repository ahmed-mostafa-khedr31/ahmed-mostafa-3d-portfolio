## Portfolio Features

- **Interactive 3D:** Computer model, skill spheres, and a star field built with `@react-three/fiber` and `@react-three/drei`.
- **Projects grid:** Category filters, with the first 8 cards shown and a View All control for the rest.
- **Reviews:** Loaded from and submitted to a live reviews API, shown in a swipeable carousel.
- **Responsive layout:** Mobile, tablet, and desktop.
- **Resume download:** CV linked from the navbar and contact section.
